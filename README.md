# Nexus ERP

Offline-first desktop ERP (login phase complete).

## Quick start

```powershell
cd C:\Users\imran.shabbir\Desktop\erp
npm install
npm run setup
npm run dev
```

Then either:
- Open http://127.0.0.1:5173 in browser, or
- Run `npm run desktop` for Electron window

See [RUN.md](./RUN.md) for full instructions.
