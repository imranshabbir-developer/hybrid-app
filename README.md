# Nexus ERP (hybrid-app)

Offline-first desktop ERP for purchase orders, suppliers, and import tracking.

## Quick start

```powershell
npm install
npm run setup
npm run dev
```

Then either:
- Open http://127.0.0.1:5173 in the browser, or
- Run `npm run desktop` for the Electron window

See [RUN.md](./RUN.md) for full instructions.
